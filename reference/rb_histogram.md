# Build a pupil-size distribution histogram

Build a pupil-size distribution histogram

## Usage

``` r
rb_histogram(data, color, title, xlab, backuplab = NULL)
```

## Arguments

- data:

  Numeric vector of pupil samples

- color:

  Fill colour for the bars

- title:

  Panel title

- xlab:

  X-axis label

- backuplab:

  Fallback x-axis label when `xlab` is `NULL`

## Value

A `ggplot` object

# Print method for `eyeris` methods boilerplate

Renders the Markdown boilerplate text to the console as-is (rather than
as a single escaped string).

## Usage

``` r
# S3 method for class 'eyeris_boilerplate'
print(x, ...)
```

## Arguments

- x:

  An `eyeris_boilerplate` object returned by
  [`boilerplate()`](https://eyeris.shawnschwartz.com/reference/boilerplate.md)

- ...:

  Unused; included for S3 consistency

## Value

The input `x`, invisibly

# Validate the `max_gap_ms` argument for interpolation

Validate the `max_gap_ms` argument for interpolation

## Usage

``` r
validate_max_gap_ms(max_gap_ms)
```

## Arguments

- max_gap_ms:

  The user-supplied maximum gap duration in milliseconds

## Value

The validated `max_gap_ms` value (`Inf` if `NULL` was supplied)
